01 — About

I turn ideas into reliable, scalable software.

I'm Kushan Dimantha, a Full-Stack Software Engineer from Sri Lanka with 4+ years of hands-on experience building web, blockchain, mobile, desktop and Linux-based applications. My work spans the full software lifecycle — from system design to development, deployment and long-term maintenance.

I hold a BSc (Hons) in IT specializing in Software Engineering at SLIIT. During my studies I conducted research on real-time emotion detection and mental-health monitoring for remote employees, later published in an international journal — an experience that deepened my appreciation for data-driven, impactful technology.

Professionally I've built secure full-stack apps, RESTful & real-time socket systems, mobile apps, npm packages, Chrome extensions, dApps and Linux desktop apps using React, Next.js, Vite, Node.js, NestJS, Go, Flutter and Electron.js — backed by MongoDB, PostgreSQL, MySQL, Redis, Pebble DB and Badger DB.

Beyond coding, I work across system design, secure auth (JWT, encryption) and DevOps — Docker, Kubernetes, CI/CD, AWS, DigitalOcean and GitHub Actions — and I've led and mentored junior engineers while keeping clean code and scalable architecture.
